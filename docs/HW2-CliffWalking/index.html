1. 作業目標

本專案實作並比較強化學習中兩種經典的時序差分(TD)演算法：Q-learning 與 SARSA。透過互動式網頁，我們可以在 Cliff Walking 環境中視覺化觀察兩者在學習過程中的行為差異、學習曲線，以及最終學習到的策略。

2. Cliff Walking 環境說明

這是一個 4x12 的網格世界，規則如下：

  • 起點位於左下角，終點位於右下角。
  • 起點與終點之間的底層區域為懸崖 (Cliff)。
  • 每移動一步，獲得獎勵 -1。
  • 若掉入懸崖，獲得獎勵 -100，並且會被立刻送回起點。
  • 到達終點後該回合(Episode)結束。

3. Q-learning 原理 (Off-policy)

Q-learning 是一種異策略 (Off-policy) 演算法。它在更新 Q 值時，總是假設下一步會採取最佳行動 (max_a' Q(s',a'))，而忽略了實際上可能因為 ε-greedy 策略而進行的隨機探索。

Q(s,a) ← Q(s,a) + α [r + γ max_a' Q(s',a') - Q(s,a)]

因此，Q-learning 會學到一條最短但最危險的路徑（緊貼懸崖邊緣）。

4. SARSA 原理 (On-policy)

SARSA 是一種同策略 (On-policy) 演算法。它在更新 Q 值時，使用的是實際選擇的下一步行動 (Q(s',a'))。這意味著它會把未來可能進行的隨機探索也考慮進去。

Q(s,a) ← Q(s,a) + α [r + γ Q(s',a') - Q(s,a)]

為了避免因為探索而掉入懸崖承受 -100 的巨大懲罰，SARSA 傾向於學習一條遠離懸崖的安全路徑。

7. 最終策略比較

在訓練完成後，我們可以看到 Q-learning 通常會選擇緊貼懸崖的最短路徑，而 SARSA 則會選擇繞遠路以確保安全。雖然 Q-learning 學到了理論上的最佳路徑，但在實際執行（仍保有探索機率）時，SARSA 的平均獎勵通常會高於 Q-learning，因為它避免了災難性的失敗。

8. 結論

根據本次在 Cliff Walking 環境的實驗比較，我們總結兩種演算法的差異如下：

  • 哪一種方法收斂較快？
    SARSA 的收斂速度在訓練階段（Online performance）看起來較快，並且能更早達到穩定的平均獎勵。這是因為 SARSA 是 On-policy，它會把 ε-greedy 探索的風險考慮進去，快速學會繞過懸崖以避免 -100 的巨大懲罰。相反地，Q-learning (Off-policy) 因為總是評估最佳行動，學到的路徑緊貼懸崖，導致在訓練階段因為隨機探索而頻繁掉入懸崖，平均獎勵的收斂過程顯得震盪且低落。
  • 哪一種方法較穩定？
    SARSA 較為穩定。 在持續保有隨機探索（ε > 0）的環境下，SARSA 的學習曲線在找到安全路徑後能保持平穩的高獎勵。而 Q-learning 因為其選擇的「最佳路徑」極度危險，只要發生隨機探索就有很高機率墜崖，因此即使其 Q 值已經收斂，它在訓練過程中的表現依然呈現極高的變異性與不穩定性。
  • 在何種情境下應選擇 Q-learning 或 SARSA？
    • 選擇 SARSA： 當「在訓練過程中的表現與安全」非常重要，且錯誤的代價極高時（例如：實體機器人導航、自動駕駛、醫療決策），應選擇 SARSA。因為它會考量自身的探索行為，從而學習出保守、安全的策略以避免災難性後果。
    • 選擇 Q-learning： 當「訓練環境是安全的模擬器（無實際危險）」，且我們最終只在乎「取得絕對最佳、最短的路徑」，並且可以在訓練完成後將 ε 設為 0 直接執行時，應選擇 Q-learning。即使它在訓練時頻繁失敗，最終取出的純 Greedy 策略卻是全域最佳解。
