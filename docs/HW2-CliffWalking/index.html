1. 作業目標

本專案實作並比較強化學習中兩種經典的時序差分(TD)演算法：Q-learning 與 SARSA。透過互動式網頁，我們可以在 Cliff Walking 環境中視覺化觀察兩者在學習過程中的行為差異、學習曲線，以及最終學習到的策略。

2. Cliff Walking 環境說明

這是一個 4x12 的網格世界，規則如下：

  • 起點位於左下角，終點位於右下角。
  • 起點與終點之間的底層區域為懸崖 (Cliff)。
  • 每移動一步，獲得獎勵 -1。
  • 若掉入懸崖，獲得獎勵 -100，並且會被立刻送回起點。
  • 到達終點後該回合(Episode)結束。

3. Q-learning 原理 (Off-policy)

Q-learning 是一種異策略 (Off-policy) 演算法。它在更新 Q 值時，總是假設下一步會採取最佳行動 (max_a' Q(s',a'))，而忽略了實際上可能因為 ε-greedy 策略而進行的隨機探索。

Q(s,a) ← Q(s,a) + α [r + γ max_a' Q(s',a') - Q(s,a)]

因此，Q-learning 會學到一條最短但最危險的路徑（緊貼懸崖邊緣）。

4. SARSA 原理 (On-policy)

SARSA 是一種同策略 (On-policy) 演算法。它在更新 Q 值時，使用的是實際選擇的下一步行動 (Q(s',a'))。這意味著它會把未來可能進行的隨機探索也考慮進去。

Q(s,a) ← Q(s,a) + α [r + γ Q(s',a') - Q(s,a)]

為了避免因為探索而掉入懸崖承受 -100 的巨大懲罰，SARSA 傾向於學習一條遠離懸崖的安全路徑。

7. 最終策略比較

在訓練完成後，我們可以看到 Q-learning 通常會選擇緊貼懸崖的最短路徑，而 SARSA 則會選擇繞遠路以確保安全。雖然 Q-learning 學到了理論上的最佳路徑，但在實際執行（仍保有探索機率）時，SARSA 的平均獎勵通常會高於 Q-learning，因為它避免了災難性的失敗。

8. 結論

當環境中存在巨大的懲罰（如掉入懸崖）且代理人必須在學習過程中執行探索時，SARSA 能夠學習到更為安全且穩健的策略。相反地，如果我們可以完全分離「訓練」與「執行」階段（訓練時承受失敗，執行時完全貪婪），Q-learning 則能找到絕對最佳的捷徑。
